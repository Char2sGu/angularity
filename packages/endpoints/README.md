# @angularity/endpoints

Declarative access to HTTP endpoints with swappable implementations.

```sh
npm i @angularity/{core,endpoints}
```

## API

### `@angularity/endpoints`

Top-level:

- `generateEndpoint`
- `generateEndpoints`
- `useEndpoints`

Services:

- `EndpointInvoker`
- `HttpClientEndpointInvoker`

Behaviors:

- `PrefixEndpointPath`
- `CacheEndpointResponse`
