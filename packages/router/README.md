# @angularity/router

Utilities for the Angular routing system, built on `@angular/router`.

```sh
npm i @angular/router @angularity/{core,router}
```

## API

### `@angularity/router`

Component Utilities:

- `linkedQueryParam`

General Utilities:

- `useChildActivatedRoute`
- `setupInjectionContextForLoadChildren`

Route Data:

- `RouteDataToken`
- `defineRouteData`
- `useRouteData`
